# Hangman Game – Python

## Project Overview
Hangman is a simple text-based word-guessing game developed using Python. The player must guess a randomly selected word one letter at a time within a limited number of incorrect attempts.

## Features
- Random selection of words from a predefined list.
- Maximum of 6 incorrect attempts.
- Displays correctly guessed letters and hides the remaining letters.
- Validates user input to accept only single alphabetic characters.
- Prevents repeated guesses of the same letter.
- Displays a success message when the word is guessed correctly.
- Reveals the correct word when the player runs out of attempts.

## Technologies Used
- Python
- Random module
- Conditional statements
- Loops
- Lists and strings
- User input and output

## How to Run
1. Install Python on your computer.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the following command:

   `python hangman.py`

5. Enter one letter at a time and try to guess the hidden word.

## Learning Outcomes
This project demonstrates the use of Python fundamentals, including loops, conditional statements, lists, strings, random selection, and input validation.
